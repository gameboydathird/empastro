🚀 About the Project
This is a modern, fast, and fully responsive website built for the Empire Gaming community. It serves as the central hub for our teams, competitive rosters (CS2, Valorant), and community updates.

The design features a cinematic, esports-inspired aesthetic with heavy typography, dynamic scrolling elements, and a custom dark theme.

🛠️ Tech Stack
This project was built from the ground up using:

Framework: Astro (for static site generation and component architecture)

Styling: Vanilla CSS (custom properties, Flexbox, CSS Grid, and keyframe animations)

Deployment: GitHub Actions & GitHub Pages

Typography: Google Fonts (Anton & Space Mono)

✨ Key Features
Modular Layouts: A centralized BaseLayout.astro ensures the navigation bar and footer are perfectly synced across all pages.

Interactive Dropdown Navigation: Accessible hover and keyboard-focus-driven dropdown menus for game rosters.

Cinematic Hero Section: Responsive, poster-style typography utilizing clamp() for fluid scaling across devices.

Scrolling Marquee: A custom CSS infinite scrolling ticker for announcements and community slogans.

CI/CD Pipeline: Automated deployments to GitHub Pages triggered on every push to the master branch.

💻 Running Locally
If you want to clone this repository and run it on your own machine, follow these steps:

1. Clone the repository:

bash
git clone https://github.com/gameboydathird/empastro.git
cd empastro
2. Install dependencies:

bash
npm install
3. Start the local development server:

bash
npm run dev
The site will be available at http://localhost:4321.

4. Build for production:

bash
npm run build
This will generate the final static files in the dist/ folder.
